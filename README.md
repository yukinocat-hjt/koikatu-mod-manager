# 恋爱活动 Mod 管理器

Koikatsu（恋爱活动）的 mod 整理工具。把下载来的一堆 `rar` / `zip` / `7z` 丢进去，自动解压、按文件类型分类，再分发到各自的目录。

不用再手动开压缩包、找 `.zipmod`、复制粘贴到 `Mods` 了。

---

## 它能做什么

```
待处理目录 ──► 7-Zip 解压 ──► 按扩展名分类 ──┬──► Mods 目录      .zipmod
  (rar/zip/7z)   (_work/temp)                ├──► 卡片目录      .png
                                             └──► 其它目录      可选，默认丢弃
```

| 文件类型 | 去向 |
|---|---|
| `.zipmod` | 你指定的 Mods 目录 |
| `.png` | 你指定的卡片 / 图片目录 |
| 其它文件 | 可选，输出到「其它」目录，默认丢弃 |

## 环境要求

- **Windows**
- **Python 3.8+**，且带 `tkinter`（官网安装时保持 `tcl/tk and IDLE` 勾选）
- **7-Zip**（解压 `rar` 必需，[下载](https://www.7-zip.org/)）
  - `zip` 会走 Python 内置 `zipfile`，没有 7-Zip 也能处理

除标准库外**零第三方依赖**。

## 快速开始

1. 双击 **`启动.bat`**
   > 它会自动探测系统里带 tkinter 的 Python，并用无控制台方式启动。找不到会给出提示。
2. 设置目录：**待处理目录**（放压缩包的地方）、**zipmod 目标**、**png 目标**
   > 也可以点「从游戏目录一键填充」，选中含 `Koikatu.exe` 的那一层，会自动填好 `Mods` 和 `UserData\chara\female`
3. 点 **扫描压缩包** → **开始整理**

首次使用建议先勾选 **试运行** 预览一遍，确认无误再取消勾选跑正式流程。

## 安全设计

整理 mod 目录这种事，最怕的就是搞丢文件。所以：

- **原压缩包不删除** — 整理完自动移进 `_已处理` 子目录，随时可以重来。解压失败的原包会**留在原地不归档**，并明确报错。
- **撤销上次整理** — `_work/last_run.json` 记录本次所有改动，撤销时把分发的文件、归档的压缩包、被覆盖的旧文件全部还原，撤回内容保留在 `_work/backup/undo_<时间戳>/`，**全程不删除任何文件**。
- **重名三策略**
  - 自动改名（默认）：`xxx.zipmod` → `xxx_1.zipmod`
  - 跳过：目标已存在就不动它
  - 覆盖：旧文件先备份到 `_work/backup/` 再写入
- **同尺寸视为重复** — 目标目录已有同名且大小一致的文件，直接跳过，避免同一批 mod 反复堆叠。
- **试运行模式** — 只预览会移动哪些文件，不落盘。

## 文件说明

| 文件 / 目录 | 说明 |
|---|---|
| `mod_manager.py` | 主程序，Python 3 + tkinter 单文件 |
| `启动.bat` | 启动器（GBK + CRLF 编码），自动探测 Python |
| `config.json` | 运行时自动生成的配置（已 gitignore） |
| `_work/` | 运行时目录：`temp` 临时解压、`backup` 备份、`last_run.json` 撤销清单（已 gitignore） |
| `_已处理/` | 原压缩包归档目录，默认位于待处理目录下 |

## 实现要点

- 解压复用系统 7-Zip：`7z x -y -sccUTF-8 -o<dest> -- <archive>`，失败时把 stderr 摘要回显到日志
- 解压到 `_work/temp` 而非系统临时目录，保证与目标目录同盘，`shutil.move` 是秒级重命名而非跨盘拷贝
- 递归提取子目录内的 `.zipmod`，跳过 `__MACOSX`、`.DS_Store`、`._*` 等垃圾文件
- 后台线程执行，界面不卡；线程只往 `queue.Queue` 投递消息，UI 由 `after()` 轮询消费
- 关闭窗口时保存配置并把待处理状态写回 `config.json`

## 常见问题

**Q：提示找不到 7-Zip？**
装一个 [7-Zip](https://www.7-zip.org/) 即可。装在非默认路径的话，日志里会显示它实际使用的位置。

**Q：`.png` 到底是角色卡还是场景卡？**
工具只按扩展名分发，具体存哪由你在界面里指定，不做内容判断。

**Q：中文文件名解压后乱码？**
已通过 `-sccUTF-8` 处理。若仍出现乱码，多半是该压缩包本身用了非标准编码打包。

**Q：能处理分卷压缩包吗？**
能，`.001` 分卷在列表中选中第一个即可，7-Zip 会自动串联后续分卷。
